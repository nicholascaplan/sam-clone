Comparisons for the site's interactive components and desktop layouts. The media examples explore how to use wide screens without losing the site's calm editorial character.

Listen & Watch: Desktop space

The whitespace itself suits the site. The problem is the very long audio rows: related metadata is separated by a large inactive span. These options preserve generous page margins while making the catalogue area work harder.

Use an information rail only when its content earns the space

The existing whitespace is preferable to arbitrary columns. Option C adds useful recording links and availability context without pulling related track information apart.

Recommended

Option A: Measured catalogue

Keep each track's title and supporting detail together, but cap the catalogue at a more readable width. The outer space becomes an intentional margin rather than a gap inside the rows.
