# Redesign Strategy Record

This document records the redesign direction. It is not an active delivery plan; current work is tracked in `docs/next-steps.md`.

## Original Problems

- Eleven top-level destinations fragmented works, recordings, projects and event history.
- Visitors had to move between separate pages to find instrumentation, media and project context.
- The original biography led with credentials rather than Samantha's artistic voice.
- Works did not consistently provide clear media or score-hire actions.

## Implemented Direction

- Reduced public navigation to Home, Works List, Listen, Watch, Biography, Writing and Contact.
- Consolidated works, recordings and films into the searchable Works & Media catalogue.
- Kept Biography, Writing and Contact as in-page routes to preserve playback and a consistent shell.
- Added media actions to relevant works, a score-request route into Contact and an in-page contact form.
- Retained project context in Spotlight Works, Biography and media cards instead of separate project pages.
- Removed the public events calendar and past-performance archive pending current content.

## Remaining Product Questions

- Whether current event or concert content should return to the homepage.
- Whether all catalogue recordings need per-item availability status.
- Whether content growth or sharing requirements justify a future multi-page architecture.
- Whether private audio or perusal-score access would materially improve commissioning enquiries.
